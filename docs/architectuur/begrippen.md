# Begrippenlijst

In de documentatie en de gebruikersinterface gebruiken we Nederlandse termen. In de code wordt Engels gebruikt.
Deze lijst geeft voor elk begrip de vertaling die in de code wordt gebruikt.

## Huidige begrippen

| Nederlands                 | Engels (code)                 | Toelichting                                               |
|----------------------------|-------------------------------|-----------------------------------------------------------|
| afdeling                   | department                    | Organisatieonderdeel en eenheid van gegevensscheiding     |
| team                       | team                          | Team binnen een afdeling                                  |
| gebruiker                  | user                          | Medewerker met een account                                |
| API-gebruiker              | api user                      | Systeemaccount voor de API                                |
| zaak                       | petition                      | Woo-verzoek, bezwaar, beroep of klacht                    |
| zaaksoort                  | petition type                 |                                                           |
| zaakvariant                | petition variant              | Woo, bezwaar, beroep, enz.                                |
| categorie                  | petition category             |                                                           |
| status                     | petition status               |                                                           |
| zaaknummer                 | petition number               |                                                           |
| toewijzing                 | (petition) assignment         | Primaire of secundaire behandelaar                        |
| verwerkingsstap            | processing step               |                                                           |
| besluit                    | decision                      |                                                           |
| contact                    | contact                       | Verzoeker, bezwaarmaker, gemachtigde, enz.                |
| bijlage                    | attachment                    |                                                           |
| notitie                    | note                          | Tijdlijnitem met tekst en eventueel bijlagen              |
| tijdlijn                   | timeline (item)               |                                                           |
| gebeurtenis                | petition event                | Bijv. verdaging, opschorting                              |
| termijn                    | term                          |                                                           |
| verdaging                  | adjournment                   |                                                           |
| opschorting                | suspension                    |                                                           |
| feestdag                   | public holiday                | Voor de termijnberekening (Algemene termijnenwet)         |
| beleidsdirectie            | policy department             |                                                           |
